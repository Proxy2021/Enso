# WHY ENSO?

> An AI sandbox that ships.

## The Problem

AI developer tools are fragmented. You use ChatGPT for research, Cursor for code editing, v0 for UI prototyping, Replit for hosting, and Notion for notes. Five subscriptions. Five contexts. No integration between any of them. And when something breaks, you wait for the vendor to fix it.

## The Solution

Enso is a single self-evolving workspace that replaces all of them. It researches, builds, deploys, and improves itself — and you own everything.

## Three Things No Other Tool Does

1. **Self-evolution** — Type `/evolve` and an AI team (project leader, architect, engineers, QA) runs a full improvement sprint on your installation. Sprint scores improved from 4.5 → 7.5 over 4 cycles.

2. **Every answer is an app** — Research becomes an interactive dashboard. Build requests become running apps. File operations become a desktop-grade file manager. Not text. Not previews. Real interactive applications.

3. **You own the factory** — Self-hosted. Your code, your data, your API keys. During setup, Claude Code personalizes the entire app for your role. A developer gets "Forge," an investor gets "Signal," a researcher gets "Nexus."

## Get Started

```bash
git clone https://github.com/Proxy2021/Enso.git && cd Enso
./setup          # macOS/Linux
.\setup.ps1      # Windows
```

Setup takes ~5 minutes. You'll need API keys for your preferred LLM provider.
